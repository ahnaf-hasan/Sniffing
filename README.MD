### 🦈 Sniffing

### 📌 What is Sniffing?

Sniffing is the process of capturing and analyzing network packets to monitor communication between devices.

It is commonly used by network administrators and security professionals for network troubleshooting, traffic analysis, and security monitoring.

---

### 🌐 Types of Sniffing

- Passive Sniffing
- Active Sniffing

---


### 📋 Information Analysis

- Source IP Address
- Destination IP Address
- Source and Destination Ports
- Network Protocols
- Packet Information
- DNS Queries
- Traffic Patterns
- Network Communication

---

### 🛡️ Prevention

- Use HTTPS and encrypted protocols.
- Use WPA2 or WPA3 secured Wi-Fi.
- Avoid unsecured public networks.
- Use VPNs when appropriate.
- Monitor suspicious network traffic.
- Avoid transmitting sensitive data over unencrypted connections.

---
